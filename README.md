# Access One

Сервис доступа к мировому интернету через Telegram.

**Купил → получил доступ → работает.**

## Концепция

Не классический VPN с кучей настроек, а простой сервис:
1. Пользователь покупает подписку в Telegram-боте
2. Получает subscription-ссылку
3. Импортирует её в Happ / v2RayTun / Hiddify
4. Пользуется

## Тарифы (MVP)

| Тариф | Цена/мес | Лимит на сервер | Устройства |
|-------|----------|-----------------|------------|
| Стандарт | 300 ₽ | — | 1 |
| Премиум | 600 ₽ | 50 пользователей | 1 |

## Реферальная система

| Кто | Что получает |
|-----|--------------|
| **Приглашённый** (перешёл по ссылке) | 7 дней **только Стандарт** (trial) |
| **Пригласивший** | +7 дней к подписке **только если у него Стандарт** |
| **Премиум** | Реферальный бонус **не начисляется** |

- Приглашённый всегда получает trial Стандарт (даже если пригласивший на Премиуме).
- Если у пригласившего нет активной подписки — активируем 7 дней Стандарта.
- Каждый успешный referral даёт +7 дней (можно приглашать много друзей).

## Стек

- **Backend**: NestJS (Node.js)
- **Bot**: grammY
- **DB**: PostgreSQL
- **Cache**: Redis
- **VPN**: Xray-core (VLESS + Reality)
- **Payments**: ЮKassa
- **Admin**: Telegram (на старте)
