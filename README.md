# Access One

Сервис доступа к мировому интернету через Telegram.

**Купил → получил доступ → работает.**

## Концепция

Не классический VPN с кучей настроек, а простой сервис:
1. Пользователь покупает подписку в Telegram-боте
2. Получает subscription-ссылку
3. Импортирует её в Happ / v2RayTun / Hiddify
4. Пользуется

## Тарифы (MVP)

| Тариф | Цена/мес | Лимит на сервер | Устройства |
|-------|----------|-----------------|------------|
| Стандарт | 300 ₽ | — | 1 |
| Премиум | 600 ₽ | 50 пользователей | 1 |

Пробный период: **7 дней** только по реферальной ссылке.

## Стек

- **Backend**: NestJS (Node.js)
- **Bot**: grammY
- **DB**: PostgreSQL
- **Cache**: Redis
- **VPN**: Xray-core (VLESS + Reality)
- **Payments**: ЮKassa
- **Admin**: Telegram (на старте)
